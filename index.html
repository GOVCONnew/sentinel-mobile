      Help · Permissions

      1 · HTTPS is required

      iOS Safari only allows camera and microphone on secure (HTTPS) pages. SENTINEL is served from GitHub Pages over HTTPS: https://govconnew.github.io/sentinel-mobile/. Opening a local file or plain-http URL will not work.

      2 · Tap START

      Safari needs a tap before it can start the camera, microphone and audio engine. Tap START on the splash screen, then choose Allow for Camera and Microphone.

      3 · Denied by mistake?

      Tap aA in the Safari address bar → Website Settings → set Camera and Microphone to Allow, then reload. Or open Settings › Apps › Safari › Camera / Microphone (older iOS: Settings › Safari) and choose Ask or Allow. Location (optional GPS tagging) is under Settings › Privacy & Security › Location Services › Safari Websites.

      4 · Add to Home Screen

      Share button → Add to Home Screen runs SENTINEL fullscreen without browser bars. Permissions may be asked again the first time it runs from the Home Screen.

      5 · Keep the screen on

      SENTINEL requests a screen wake lock (iOS 16.4+) and plays a silent muted video as fallback. For long watches also set Settings › Display & Brightness › Auto-Lock › Never and keep the phone on power. If the screen locks or you switch apps, iOS stops the camera/mic — return and tap Resume.

      6 · Silent switch & audio

      The ring/silent switch does not block microphone input; SENTINEL never plays sound. Phone calls, Siri or another app using the mic will interrupt sound classification. Orange dot = mic in use, green dot = camera in use.

      7 · Fallbacks

      No WebGL → WASM/CPU backend (slower). No microphone → sound panel disabled. No IndexedDB (e.g. some Private modes) → snapshots off. No file sharing → download links instead. Everything runs on-device; nothing is uploaded. Models load once from CDN / this site and are then browser-cached.

      Models

      COCO-SSD 2.2.3 (TF.js, 80 COCO classes) via jsDelivr. YAMNet (Google, AudioSet 521 classes) vendored in this site under models/yamnet/. Detections are approximate — COCO has no deer/fox/boar classes; such animals may be reported as the nearest class (dog, horse, cow, sheep, bear).
